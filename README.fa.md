## اضافه کردن یک سایت

فقط اسم سایت را بنویسید. پرامپ یک سرور فقط‌خواندنی با ساختار همین پروژه می‌سازد و پول‌ریکوئست را باز می‌کند.

1. خط `سایت:` را در [prompt.md](prompt.md) پر کنید و همهٔ جعبه را به ایجنت بدهید.
2. ایجنت `servers/<name>-mcp/` را اضافه می‌کند و پول‌ریکوئست را روی [alizare84/iran-mcp](https://github.com/alizare84/iran-mcp) باز می‌کند.
3. قبل از آمدن سرور به کاتالوگ، پول‌ریکوئست مرور می‌شود.

قرارداد نام‌ها، فایل‌ها، ابزارها و کلاینت HTTP در [format.md](format.md) است. اگر سایت از قبل در فهرست باشد، یا داده‌اش پشت ورود باشد، ایجنت پول‌ریکوئست باز نمی‌کند.

## اجرای یک سرور

```json
{
  "mcpServers": {
    "digikala": { "command": "uvx", "args": ["digikala-mcp"] }
  }
}
```

`uvx` در اولین اجرا بسته را نصب می‌کند. دو سرور را خود سایت میزبانی می‌کند: پس‌آورد در `https://pasavard.ir/api/mcp` و سواپ‌ولت در `https://swapwallet.app/mcp` (با ورود).
